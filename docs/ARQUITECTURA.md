# Martie — arquitectura inicial

## Stack
- React + Vite
- Supabase: Auth, PostgreSQL, Storage y Edge Functions
- Vercel: frontend/deploy
- GitHub: repositorio

## Reglas
- Sin pagos con tarjeta en línea.
- Tarjeta: terminal física en sucursal.
- Efectivo: pickup.
- Transferencia: comprobante por WhatsApp + validación manual.
- Invitados pueden comprar.
- Martie Club para usuarios registrados.
- El logo definitivo queda pendiente.
